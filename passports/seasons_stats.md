- Сезоны: **1950–2017**; `Year` — год **окончания** сезона
  (сезон 1990/91 → `Year = 1991`).
- Уникальных игроков: **3,921**; кодов команд: **69** (включая `TOT`).
- Пустых строк (полностью NaN, кроме индекса): **67** — удалять; служебную колонку
  `Unnamed: 0` и пустые колонки `blanl`, `blank2` при загрузке отбрасывать.
- **2,123** строк `Tm = "TOT"`; строк, вовлечённых в дубликаты `(Player, Year)`: **6,450**
  (лишних сверх первого вхождения: **4,338**; это норма: `TOT` + строки по командам, либо несколько команд).
- `TOT` совпадает с суммой строк команд: G — 99.8%, PTS — 99.8%
  (2,089 проверенных пар игрок-сезон).

**Правило мержа:** для сезонных итогов игрока брать `Tm == "TOT"`; иначе — сумма по строкам команд.
